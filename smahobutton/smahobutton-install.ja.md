# スマホボタンの入れ方

画面の上に、丸いボタンを出すアプリです。
タップや長押しで、スクリーンショットや音量などができます。

## スマホに入れる

1. 届いた `smahobutton.apk` を、スマホに保存します。
2. 「ファイル」アプリで、その APK を開きます。
3. 「インストール」を押します。
4. 「提供元が不明のアプリ」と出たら、許可します。
   設定の画面が開いたら、このアプリからのインストールをオンにして、戻ります。
5. Play プロテクトの警告が出たら、「詳細」を押して「インストールする」を選びます。
   自分用のアプリなので、この警告は出ます。
6. 終わったら「開く」を押します。

## はじめにやること

アプリの「はじめにやること」を、上から順に済ませます。
終わった項目には ✓ が付きます。

1. **他のアプリの上に表示**
   「設定を開く」→ スマホボタンをオンにします。
   ボタンを、ほかのアプリの上に出す許可です。
   「アプリはアクセスを拒否されました」と出たり、グレーで押せないときは:
   「アプリ情報を開く」→ 右上の ︙ → 「制限付き設定を許可」
   そのあと、もう一度オンにします。
2. **ユーザー補助**
   「設定を開く」→ スマホボタンをオンにします。
   戻る、ホーム、スクリーンショットに使います。
   ここでも同じメッセージが出たら、上と同じく
   「アプリ情報を開く」→ 右上の ︙ → 「制限付き設定を許可」
   そのあと、もう一度オンにします。
3. **通知**
   「許可する」を押します。
   ボタンを動かし続けるための通知です。音は出ません。
4. **おやすみモード**
   マナーモードを使うときだけ必要です。使わないなら、飛ばして大丈夫です。
5. **バッテリー制限なし**
   「許可」または「制限なし」を選びます。
   画面を消したあとも、ボタンが止まらないようにします。

全部に ✓ が付いたら、上のスイッチをオンにします。
画面の右はしに、うすい丸いボタンが出ます。
準備が終わると、「✓ 準備はぜんぶ済んでいます」の一行になります。
タップすると、一覧をまた見られます。

## 使い方

- ボタンは指で動かせます。離すと、左か右の端にくっつきます。
- 「ボタンの設定」で、色・大きさ・うすさ・マークを変えられます。
  ボタンは 1 個から 5 個までです。
- タップ、ダブルタップ、長押しに、別々の動きを入れられます。
  いらないところは「なし」のままで大丈夫です。
- 「タップでメニュー」をオンにすると、タップで小さなメニューが開きます。
- 「アプリごとの音量」で、アプリごとに音の大きさを覚えさせられます。
  そのアプリを開くと、覚えた音量になります。
  「アプリを閉じたら元の音量にもどす」は、最初からオンです。
- ボタンの動きに「この画面の音量を覚える」を入れると、今開いているアプリの音量をその場で覚えます。
- スイッチをオフにすると、ボタンは消えます。
- オンのままスマホを再起動すると、ボタンは自動で戻ります。
- 「控え（バックアップ）」に、ボタンが3つあります。
  「ドライブに保存」は、Google にログインして「Grok」フォルダへ保存します。前の控えはゴミ箱に移し、新しい1件だけ残します。
  「バックアップを保存」は、保存先を選ぶ画面が開きます。
  「バックアップから復元」は、ファイルを選ぶと「上書きする」か聞いてから戻します。

## 困ったとき

- ボタンが出ない: 「はじめにやること」の ✓ を確認して、スイッチを入れ直してください。
- 「アプリはアクセスを拒否されました」と出る: アプリ情報の右上「︙」から「制限付き設定を許可」を選び、もう一度許可してください。上に表示でも、ユーザー補助でも同じです。
- ドライブに保存で「Google Cloud に Android の登録がまだです」と出たら、アプリを作った人に伝えてください。
- ドライブに保存できないときは、「バックアップを保存」を使ってください。
- スクリーンショットや戻るが動かない: ユーザー補助がオンか見てください。
- マナーモードが動かない: おやすみモードの許可をオンにしてください。
- ライトが動かない: カメラの許可を求められたら、許可してください。
- アプリ情報で「強制停止」を押すと止まります。そのときは、アプリを開き直してください。
