# タスクの入れ方

スマホに入れるファイルは `tasks-alarm.apk` です。中身は今の「タスク」と同じ画面で、メモに時刻を入れるとその時刻に鳴ります。

## インストール

1. `tasks-alarm.apk` をスマホに送ります。
2. 「ファイル」アプリで、その APK をタップします。
3. 「提供元が不明なアプリ」と出たら、案内に従って許可します。
4. 「タスク」を開きます。署名は開発用（デバッグ）です。Play プロテクトの注意が出ても、自分用なので「インストールする」で大丈夫です。

## 最初にオンにするもの

開くと「アラームの準備」が出ます。

1. **通知**
2. **ロック画面**（全画面表示）
3. **バッテリー**は「制限なし」

音量ボタンで **アラームの音量** も上げておいてください。おやすみモードのあいだは鳴らないことがあります。

## 今のデータを入れる

1. 今のタスク（ブラウザ）で「控え」→「バックアップを保存」をし、`tasks-backup-….json` をスマホに置きます。
2. アプリの「控え」→「バックアップから復元」で、そのファイルを選びます。
3. 上書きしていいか聞かれたら「上書きする」を押します。

時刻の入っていない昔のメモも、そのまま使えます。鳴るのは、日付と時刻の両方があるメモだけです。

## 使い方

- 「メモ」の入力欄、「いつもの」、日付と時刻の入れ方は、今までと同じです。時刻は空でも大丈夫です。
- 「メモ」の上に月のカレンダーがあります。点の色は、メモ・掃除の次回・防災グッズの期限・車の次回です。削除したタブの点は出ません。
- 日を押すと、その日がメモの日付になり、下にその日のメモ（時刻の順、時刻なしはあと）と掃除・防災・車が出ます。掃除・防災・車を押すと、そのタブで開けます。
- 鳴るのは、日付と時刻の入ったメモだけです。掃除・防災・車はカレンダーと朝のまとめに出るだけで、その時刻には鳴りません。
- 「控え」の「朝のまとめ」で、通知の時刻を変えられます。最初は朝6時（日本時間）です。その日に何もないときは通知しません。アプリを閉じていても出ます。まとめには、メモと、期限のある掃除・防災・車・自分で足したタブが入ります。
- 掃除・防災・車と、期限のある自分のタブには「ずらす」があります。その回の期限だけ別の日に動かせます。「◯/◯にずらし中」と出て、「元に戻す」で戻せます。やった（交換した・入れ替えた）あとは、やった日からいつもの間隔で次の期限になります。
- 「控え」の「時刻に鳴らすタブ」で、タブごとに、時刻を入れた項目をその時刻に鳴らすか選べます。最初はメモだけオンです。
- 鳴っている画面の「5分後にもう一度」で、5分後にまた鳴ります。ロック中でも画面いっぱいに出ます。
- データはこのスマホの中だけに残ります。今のバックアップからも戻せます。
- 「控え」の「ドライブに保存」は、スマホのGoogleアカウントでドライブの「Grok」フォルダに `tasks-backup-日付.json` として保存します。保存できたあと、このアプリの古いバックアップはゴミ箱へ移し、新しい1件だけ残します。Google Cloud にこのアプリの登録がまだのときは「Google Cloud に Android の登録がまだです」と出ます。ログインをやめたときは「Googleへのログインをキャンセルしました」と出ます。
